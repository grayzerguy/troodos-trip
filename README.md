# טיול טרודוס – PWA

אפליקציית ווב סטטית (HTML/CSS/JS וניל, בלי build) לטיול הקבוצתי בהרי טרודוס. עובדת בנייד גם בלי קליטה, ואפשר להתקין אותה למסך הבית.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד בלבד – אין בו תוכן של הטיול |
| `styles.css` | עיצוב, mobile-first, dark mode אוטומטי |
| `app.js` | ניתוב בין הטאבים, רינדור מתוך `trip.json`, מזג אוויר, זריחה/שקיעה |
| `sw.js` | Service Worker – עבודה אופליין |
| `manifest.webmanifest` | הגדרות התקנה כאפליקציה |
| `trip.json` | **כל התוכן** |
| `gpx/` | קובצי המסלולים |
| `icons/` | אייקונים 192/512 (placeholder) |

## עדכון התוכן (`trip.json`)

1. עורכים את `trip.json` (אפשר ישירות בעורך של GitHub).
2. מעדכנים את `trip.lastUpdated` (למשל `"2026-11-01 18:00"`). השדה מוצג בכותרת האפליקציה.
3. בודקים שה-JSON תקין, למשל: `python3 -m json.tool trip.json`.
4. עושים commit ו-push. **אין צורך** להעלות את הגרסה ב-`sw.js` כשמשנים רק את `trip.json`: הקובץ נטען network-first, ומשתמשים שהאפליקציה פתוחה אצלם יראו את הבאנר "יש עדכון, לחץ לרענון".

### מבנה השדות

- **תאריכים:** `YYYY-MM-DD`. **תאריך ושעה:** `YYYY-MM-DDTHH:mm` לפי שעון קפריסין, בלי אזור זמן.
- **קואורדינטות:** `lat`/`lng` עשרוניים. ערך `0,0` נחשב חסר, ואז כפתורי הניווט מוסתרים.
- **טלפונים:** בפורמט בינלאומי (`+357...`, `+972...`). שדה ריק מסומן "יש להשלים" במקום כפתור חיוג.
- `itinerary[].routeId` צריך להתאים ל-`routes[].id`, ו-`itinerary[].hotelId` ל-`hotels[].id`.
- `routes[].difficulty`: הטקסט קובע את צבע התגית (מכיל "קל" → ירוק, "קשה" → אדום, אחרת צהוב).
- `gear`: הסימונים נשמרים לפי `קטגוריה|פריט`. שינוי שם של פריט יאפס את הסימון שלו.
- `emergency.numbers`: המספר `112` מוצג ככפתור הגדול בראש מסך החירום.

### הוספת מסלול

1. שמים את קובץ ה-GPX בתיקייה `gpx/` (למשל `gpx/new-trail.gpx`).
2. מוסיפים אובייקט ל-`routes` עם `"gpx": "gpx/new-trail.gpx"`.
3. האפליקציה מבקשת מה-Service Worker לשמור כל GPX שמופיע ב-`trip.json`, כך שהוא זמין אופליין אחרי הפתיחה הבאה עם רשת.

> ⚠️ קובצי ה-GPX הקיימים הם **placeholder** (מסלול גאומטרי מומצא). להחליף אותם בקבצים אמיתיים, מ-Wikiloc או ממקור אחר, לפני הטיול.
>
> ⚠️ כל הטלפונים, מספרי ההזמנה והשמות ב-`trip.json` הם דוגמה. המספרים היחידים שהם אמיתיים הם 112 ו-199. **חובה** להשלים ולאמת את הטלפונים של בתי החולים, השגרירות והביטוח.

## עדכון קוד האפליקציה

בכל שינוי ב-HTML, CSS, JS, באייקונים או ב-GPX מעלים את `VERSION` בראש `sw.js` (`'v1'` → `'v2'`). בלי זה, משתמשים ימשיכו לקבל את הגרסה השמורה (cache-first). אחרי העלאת הגרסה יופיע אצלם הבאנר "יש עדכון, לחץ לרענון".

## הרצה מקומית

```bash
python3 -m http.server 8080
```

ופותחים את http://localhost:8080. Service Worker עובד רק על `localhost` או על HTTPS.

**בדיקת אופליין:** פותחים פעם אחת עם רשת, ואז DevTools → Application → Service Workers → מסמנים **Offline** (או לשונית Network → Offline) ומרעננים. האפליקציה צריכה להיטען, באנר "מצב אופליין" מוצג, ומזג האוויר מוצג מהשמירה האחרונה.

## פריסה ל-GitHub Pages

1. יוצרים repository חדש ב-GitHub (למשל `troodos-trip`).
2. מתוך התיקייה הזו:
   ```bash
   git init
   git add .
   git commit -m "Troodos trip PWA"
   git branch -M main
   git remote add origin https://github.com/<USER>/troodos-trip.git
   git push -u origin main
   ```
3. ב-GitHub: **Settings → Pages → Build and deployment**. ב-Source בוחרים **Deploy from a branch**, ב-Branch בוחרים `main` ו-`/ (root)`, ולוחצים Save.
4. אחרי דקה-שתיים האתר זמין ב-`https://<USER>.github.io/troodos-trip/`.
5. שולחים את הקישור לקבוצה. כל אחד פותח אותו **פעם אחת עם רשת**, ואז:
   - **iPhone (Safari):** כפתור שיתוף ← "הוסף למסך הבית".
   - **Android (Chrome):** תפריט ⋮ ← "התקן אפליקציה" / "הוסף למסך הבית".

כל הנתיבים בפרויקט יחסיים, לכן האפליקציה עובדת גם תחת תת-נתיב (`/troodos-trip/`) בלי שינויים.

> 💡 לפני שיוצאים לאזור בלי קליטה, כדאי שכל משתתף יפתח את טאב "מזג אוויר" ואת טאב "מסלולים", כדי שהתחזית העדכנית תישמר במכשיר.
>
> 🔒 שימו לב: GitHub Pages ציבורי. כל מי שיש לו את הקישור יראה את הטלפונים ומספרי ההזמנה. אם זה מפריע, השתמשו ב-repository פרטי עם Pages (דורש חשבון בתשלום) או השאירו את השדות הרגישים ריקים.
